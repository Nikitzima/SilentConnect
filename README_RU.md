**SilentConnect** — высокодоступная распределённая мультипротокольная платформа защищённого туннелирования и автоматизации продаж, спроектированная для устойчивой работы в условиях глубокого анализа пакетов (DPI), манипуляций с сетевым трафиком и отказов датацентров. Платформа объединяет Telegram-бота для автоматизации продаж, динамическую генерацию подписок для различных клиентов, управление панелями Xray/3X-UI, хаб слотов устройств AmneziaWG с квотированием трафика и автоматизированное аварийное переключение между узлами.

## Обзор архитектуры

SilentConnect работает на базе географически распределённой топологии узлов Primary–Standby, спроектированной для максимальной отказоустойчивости и быстрой восстанавливаемости:

```text
                                         [ Пользователи и Клиенты ]
                                                      │
                 ┌────────────────────────────────────┴────────────────────────────────────┐
                 │                                                                         │
       [ HTTPS: Магазин и Подписки ]                                          [ VPN-трафик (Обход DPI) ]
                 │                                                                         │
       https://<SUB_DOMAIN>                                                       https://<EDGE_DOMAIN>
    (API Gateway / Edge Буфер)                                                      (Прямой A-Record)
                 │                                                                         │
                 ▼                                                                         │
┌──────────────────────────────────────────────┐                                           │
│          NL MASTER (Основной Узел)           │                                           │
│                                              │                                           │
│  [ Xray Dokodemo-Door Мультиплексор (:443) ] │◄──────────────────────────────────────────┤
│         │                          │         │                                           │
│  (SNI: Web / Sub)           (SNI: Reality)   │                                           │
│         ▼                          ▼         │                                           │
│    [ Caddy v2 ]             [ Xray Inbound ] │                                           │
│   (TLS Term :4430)         (Vision / XHTTP)  │                                           │
│    ├── Web Shop (:3090)     (gRPC 29443)     │                                           │
│    └── SubJSON  (:3088)            │         │                                           │
│         │                          │         │                                           │
│         ▼                          │         │                                           │
│  [ SQLite WAL Мастер-БД ]  ◄───────┘         │                                           │
│  • vpn_shop.db  • x-ui.db                    │                                           │
│  • Telegram Bot (Активный демон)             │                                           │
│  • Hysteria 2 (:38443) & AWG (:44121)        │◄───────────────────┐                      │
└──────────────────────┬───────────────────────┘                    │                      │
                       │                                            │                      │
         [ Авто-push снапшотов каждые 3 мин ]                       │                      │
            (sync_primary_to_standbys.sh)                           │                      │
                       │                                            │                      │
        ┌──────────────┴──────────────┐                             │                      │
        ▼                             ▼                             │                      │
┌───────────────────────────┐ ┌───────────────────────────┐         │                      │
│   PL STANDBY (10 Gbps)    │ │   FI STANDBY (Резерв)     │         │                      │
│                           │ │                           │         │                      │
│ • SQLite Реплика (Sync)   │ │ • SQLite Реплика (Sync)   │         │                      │
│ • SubJSON & Web (Standby) │ │ • SubJSON & Web (Standby) │         │                      │
│ • Xray Reality (АКТИВЕН)  │ │ • Xray Reality (АКТИВЕН)  │◄────────┼──────────────────────┘
│ • Hysteria 2 & AWG АКТИВНЫ│ │ • Hysteria 2 & AWG АКТИВНЫ│         │
└─────────────┬─────────────┘ └─────────────┬─────────────┘         │
              ▲                             ▲                       │
              │                             │                       │
              └─────────────────────────────┴───────────────────────┘
                     [ Прямой транзит трафика через все узлы ]
                     (VLESS Reality, Hysteria 2, AmneziaWG)
```

### Ключевые архитектурные решения
- **Разделение плоскости управления и данных**: Биллинг, Telegram-бот и генератор подписок полностью изолированы от передачи сетевых пакетов. Технические работы на веб-сервисах не прерывают работу уже установленных VPN-соединений.
- **Многоуровневая маскировка DPI**: Сочетание VLESS с XTLS-Reality маскировкой под легитимные зарубежные ресурсы (`minClientVer: 0.0.0`), мультиплексированного потока HTTP/2 (XHTTP), Hysteria 2 с утверждённой обфускацией `gecko` и port hopping (UDP 38443, редиректы с 443 и 30000–40000), а также AmneziaWG с мусорными пакетами и рандомизацией заголовков (`Jc/Jmin/Jmax/S1-S4/H1-H4`).
- **Аварийный Anycast-буфер (Vercel Edge)**: Геораспределённый Anycast reverse proxy, мгновенно перенаправляющий веб-запросы к доступным Standby-узлам без ожидания обновления DNS-кэша у локальных интернет-провайдеров.

## Микросервисы и компоненты

### 1. `vpn_shop.bot` (Движок Telegram-бота)
- **Путь**: [`vpn-shop/vpn_shop/bot.py`](vpn-shop/vpn_shop/bot.py)
- **Описание**: Отказоустойчивый демон Telegram-бота на базе конечных автоматов (FSM) для онбординга клиентов, выбора тарифов, применения промокодов, реферальной программы и обработки платежей.
- **Ключевые модули**:
  - `ShopBot`: FSM-контроллер сессий пользователей, интерактивных меню и колбэков.
  - `Provisioner` ([`provisioning.py`](vpn-shop/vpn_shop/provisioning.py)): Слой интеграции с REST API 3X-UI и базой данных SQLite.
  - `Catalog` ([`catalog.py`](vpn-shop/vpn_shop/catalog.py)): Модуль расчёта стоимости тарифов (3, 6, 9 устройств со скидками за период).

### 2. `vpn_shop.web` (Веб-витрина и личный кабинет)
- **Путь**: [`vpn-shop/vpn_shop/web.py`](vpn-shop/vpn_shop/web.py)
- **Описание**: Асинхронный веб-сервер на порту `3090` за обратным прокси Caddy.
- **Возможности**:
  - Тёмная адаптивная тема для ПК и мобильных устройств.
  - Чекаут через Систему быстрых платежей (СБП) с фоновым опросом статуса оплаты.
  - Хаб слотов AmneziaWG: скачивание файлов конфигурации `.conf`, генерация PNG QR-кодов и онлайн-переименование устройств.
  - Защита от ботов Cloudflare Turnstile с автоматическим fallback.

### 3. `subjson-service` (Генератор клиентских конфигураций)
- **Путь**: [`subjson-service/app.py`](subjson-service/app.py)
- **Описание**: Высокопроизводительный сервис генерации подписок на порту `3088`.
- **Возможности**:
  - Маршруты выдачи: `/singbox/{sub_id}`, `/clash/{sub_id}`, `/happ/{sub_id}`, `/streisand/{sub_id}`.
  - Мастер настройки подключения: `/{SECRET_SEGMENT}/import/{sub_id}` с автоопределением ОС и кнопками импорта в 1 клик.
  - Token-Bucket rate limiter (`RATE_LIMIT_RPM=1200`) и LRU-кэширование профилей в памяти.

### 4. `awg_manager` и хаб слотов AmneziaWG
- **Путь**: [`vpn-shop/vpn_shop/awg_manager.py`](vpn-shop/vpn_shop/awg_manager.py) и [`vpn-shop/vpn_shop/awg_traffic.py`](vpn-shop/vpn_shop/awg_traffic.py)
- **Описание**: Менеджер жизненного цикла пиров и распределённого учёта трафика AmneziaWG.
- **Возможности**:
  - Выделение персональных слотов устройств (3, 6 или 9 слотов) в подсетях `10.8.1.0/24`, `10.8.2.0/24`, `10.8.3.0/24`.
  - Учёт квот трафика (250 ГБ, 500 ГБ, 1000 ГБ на 30-дневный расчётный цикл UTC).
  - Мягкая приостановка пиров WireGuard при исчерпании лимита при сохранении 100% безлимитного доступа через VLESS Reality.

## Катастрофоустойчивость и переключение

```text
               [ Сбой или авария Primary-мастера ]
                                │
             (1) Запуск оркестратора: switch_primary.py
                 • Проверка доступности (--preflight)
                 • Верификация целостности SQLite
                 • Перевод Standby-ноды в Primary
                 • Переключение A-записей Cloudflare
                                │
               [ Standby обрабатывает весь трафик ]
                                │
             (2) Аварийный шлюз (Vercel Anycast)
                 • Мгновенный прокси для веб-витрины и подписок
                 • Исключение задержек DNS-кэша локальных провайдеров
```

- **Непрерывная репликация снапшотов**: Скрипт `sync_primary_to_standbys.sh` запускается каждые 3 минуты по cron, создавая консистентный `.backup` базы `vpn_shop.db` и отправляя его вместе с ключами X-UI на узлы PL и FI.
- **Оркестрация переключения**: Переключение роли Primary осуществляется утилитой `switch_primary.py` (с поддержкой режимов `--dry-run` и `--preflight`). Исторические сценарии переключения на узле FI (`promote_fi.sh` / `demote_fi.sh`) сохранены на сервере.
- **Аварийный Edge-шлюз**: Описан в [docs/EDGE_FAILOVER_ARCHITECTURE.md](docs/EDGE_FAILOVER_ARCHITECTURE.md) и [docs/HA_DISASTER_RECOVERY.md](docs/HA_DISASTER_RECOVERY.md), обеспечивая нулевой простой при сбоях магистральных маршрутов.

## Telegram-бот и сценарии управления

### Пользовательские команды
- `/start` — Главное меню, проверка подписки и онбординг.
- `/prices` — Обзор тарифной сетки (3, 6, 9 устройств на 1, 3, 6, 12 месяцев).
- `/pay` — Оформить заказ или продлить активный доступ.
- `/cabinet` — Ссылки на персональный кабинет и мастер импорта.
- `/help` — Пошаговые инструкции по настройке под каждую ОС.
- `/faq` — Ответы на популярные вопросы пользователей.
- `/rules` — Условия предоставления сервиса и политика конфиденциальности.
- `/support` — Связь со службой поддержки.

### Панель администратора (`/admin`)
- **Диагностика сервера**: Загрузка процессора, памяти, активные сокеты и статус сервисов systemd.
- **Топ по трафику**: Список наиболее активных потребителей полосы пропускания.
- **Управление профилями**: Включение, мягкое отключение и проверка профилей по идентификатору.
- **Партнёрская программа**: Балансы рефералов и проведение выплат комиссионных.
- **Генератор промокодов и инвайтов**: Создание скидочных купонов и одноразовых инвайт-ссылок.
- **Управление заказами**: Подтверждение и отмена платежей в один клик.

## Веб-витрина и личный кабинет

- **Главная страница**: Современный интерфейс с интерактивным выбором тарифов и оплатой через СБП.
- **Авторитетная тарифная матрица** (из `catalog.py`):
  - **3 устройства**: 149 ₽ / месяц (250 ГБ квота AWG + безлимитный VLESS)
  - **6 устройств**: 199 ₽ / месяц (500 ГБ квота AWG + безлимитный VLESS)
  - **9 устройств**: 235 ₽ / месяц (1000 ГБ квота AWG + безлимитный VLESS)
  - *Скидки за длительность*: -10% за 3 месяца, -20% за 6 месяцев, -30% за 12 месяцев (с округлением цен до психологических девяток).
- **Хаб слотов устройств**: Удобное управление конфигурациями каждого устройства, скачивание персональных файлов `.conf`, показ PNG QR-кодов и быстрое переименование.

## Деплой и быстрый старт

### Системные требования
- **ОС**: Ubuntu 24.04 LTS или Debian 13 (Trixie).
- **Окружение**: Python 3.11+, Docker, Caddy v2, SQLite 3.35+.

### Запуск сервисов через Systemd
```bash
# 1. Запуск сервиса подписок SubJSON
systemctl enable --now subjson.service

# 2. Запуск веб-витрины и Telegram-бота
systemctl enable --now vpn-shop-web.service vpn-shop-silentconnect.service

# 3. Проверка слушающих портов
ss -tulpn | grep -E '3088|3090|443|38443|44121'
```
