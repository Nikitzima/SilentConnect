> **Статус:** Одобрено в проектирование

> **Авторы:** Команда разработки SilentConnect

## 1. Предпосылки и решаемая проблема

### 1.1. Ограничения существующих подходов контроля устройств
В ходе исследования и нагрузочного анализа выявлены критические архитектурные тупики классических методов ограничения устройств:
1. **Жесткий `limitIp` через Fail2ban (3X-UI):**
   - Блокировка по IP-адресу не подходит для мобильных сетей: при переходе с домашнего Wi-Fi на 4G у смартфона на 15–30 секунд активны сразу два IP. Жесткий лимитер дропает связь прямо во время звонка.
   - В гео-распределенном кластере (NL, PL, FI) лимиты 3X-UI действуют строго локально на каждой ноде. Пользователь может запустить 3 устройства на Нидерландах и 3 на Польше, обойдя лимит.
   - Hysteria 2 работает по UDP мимо стека 3X-UI и не поддаётся контролю через `limitIp`.
2. **Аппаратный `X-HWID` (Remnawave):**
   - Клиент Happ передает заголовок `X-HWID`, однако официальный Sing-box, Clash Verge и v2rayN принципиально **не передают HWID** из соображений цифровой приватности пользователей. Требование обязательного HWID отсекает до 50% аудитории.
3. **Родовая травма WireGuard / AmneziaWG:**
   - В WireGuard один `.conf` файл намертво привязан к одной паре ключей и одному туннельному IP. Если запустить один файл на двух девайсах, сервер постоянно флапает сессии, и соединение ложится на обоих устройствах.
   - Один файл Amnezia привязан к **одному серверу**. Для мульти-локаций нужны отдельные файлы.

## 2. Концепция «Мастер-Кабинет и Слоты Устройств»

Вместо попыток шпионить за пользователем вводится прозрачная и честная **Модель Слотов Устройств** (аналог Netflix / Spotify / Apple Family / Mullvad):

```
┌────────────────────────────────────────────────────────────────────────┐
│             ЛИЧНЫЙ КАБИНЕТ ПОДПИСКИ (sub.example.com)                  │
│                       Тариф: 3 устройства                              │
├────────────────────────────────────────────────────────────────────────┤
│ 📱 Слот 1: [ iPhone 15 Pro ✏️ ]                            🟢 Активен  │
│    Тип: Универсальная подписка (Happ / Sing-box / Clash)               │
│    Все серверы (NL, PL, FI) включены автоматически                     │
│    [Копировать ссылку] [Открыть в Happ] [Сбросить ключ]                │
├────────────────────────────────────────────────────────────────────────┤
│ 🖥️ Слот 2: [ ПК Игровой ✏️ ]                               🟢 Активен  │
│    Тип: Бронебойный туннель AmneziaWG (L3)                             │
│    Сервер: 🇵🇱 Польша (Пинг: 34 мс)                                     │
│    [Скачать .conf] [QR-код] [Сменить сервер] [Удалить]                 │
├────────────────────────────────────────────────────────────────────────┤
│ ⚪ Слот 3: [ Свободный слот ]                                           │
│    [ + Подключить устройство (Happ / Sing-box / Amnezia) ]             │
└────────────────────────────────────────────────────────────────────────┘
```

### 2.1. Два режима подключения для каждого слота
При активации слота пользователь выбирает подходящий режим:

| Режим | Для каких приложений | Серверы | Как работает |
| :--- | :--- | :--- | :--- |
| **Универсальный (L7)** | **Happ**, **Sing-box**, **Clash**, **Streisand**, **v2rayN** | **Все сразу** (NL, PL, FI) | Выдаётся персональная ссылка подписки слота. Внутри уже зашиты все протоколы и страны с авто-балансировкой. |
| **Бронебойный (L3)** | **Amnezia VPN / WG 3.1** | **Один выбранный** (NL / PL / FI) | Генерируется нативный `.conf` файл со всеми параметрами обфускации (`Jc`, `S1`, `H1-H4`) под конкретную страну. |

## 3. Инновация: Замер пинга прямо в браузере перед созданием AmneziaWG

Поскольку конфиг AmneziaWG жестко привязан к одному серверу, пользователю критически важно выбрать наилучшую локацию **до того, как скачать файл**.

### Механика In-Browser Ping Probe
При выборе AmneziaWG прямо в модальном окне ЛК запускается JavaScript-зонд:
1. Браузер отправляет параллельные легковесные HTTP HEAD / WebSocket ping-запросы к edge-хостам нашей инфраструктуры:
   - `https://edge.example.com/ping` (Нидерланды)
   - `https://pl.example.com/ping` (Польша)
   - `https://fi.example.com/ping` (Финляндия)
2. Замеряется реальный RTT (Round Trip Time) от конкретного провайдера пользователя (МТС, Билайн, Ростелеком, Wi-Fi).
3. Интерфейс подсвечивает результат:
   - 🇵🇱 **Польша:** `34 мс` 🟢 *(Рекомендуется — минимальный пинг)*
   - 🇳🇱 **Нидерланды:** `48 мс` 🟢 *(Отлично)*
   - 🇫🇮 **Финляндия:** `62 мс` 🟡 *(Запасной)*
4. Пользователь в один клик выбирает победившую страну, жмёт «Подтвердить» — и моментально получает готовый `.conf` и QR-код.

## 4. Пользовательский опыт и функции управления

1. **Кастомное переименование слотов:**
   - Поле ввода с валидацией до **16 символов** (например: *«iPhone 15»*, *«Рабочий ноут»*, *«ПК Дача»*).
   - Инлайн-сохранение через AJAX без перезагрузки страницы.
2. **Говорящие имена файлов:**
   - При скачивании файл называется не абракадаброй, а понятно:  
     `SilentConnect_iPhone_15_PL.conf`.
3. **QR-код в модальном окне:**
   - Для мобильной Amnezia: нажал «QR-код» на экране ноутбука -> навёл камеру телефона -> туннель добавлен за 2 секунды.
4. **Смена страны в слоте Amnezia:**
   - Если пользователь хочет переключить устройство с NL на PL:
     - Нажимает «Сменить сервер».
     - Проходит экспресс-тест пинга.
     - На сервере NL старый пир **мгновенно удаляется из памяти и конфига** (`awg set awg0 peer <key> remove`), а на сервере PL активируется новый.
     - Старый файл на телефоне мгновенно перестает работать, исключая параллельный доступ.

## 5. Жизненный цикл и безопасность (Zero-Leak & Zero-Abuse)

```
                  ┌───────────────────────────────┐
                  │      Оплаченная подписка      │
                  │   Слоты 1..N активны на узлах │
                  └──────────────┬────────────────┘
                                 │
                   (Истёк срок / Не оплачено)
                                 ▼
                  ┌───────────────────────────────┐
                  │        ЗАМОРОЗКА (Pause)      │
                  │  1. VLESS: disable в X-UI     │
                  │  2. AWG: awg set ... remove   │
                  │  (Ключи сохраняются в БД)     │
                  └──────────────┬────────────────┘
                                 │
            ┌────────────────────┴────────────────────┐
     (Оплата продления)                    (14 дней без оплаты)
            ▼                                         ▼
┌───────────────────────────────┐         ┌───────────────────────────────┐
│     МГНОВЕННЫЙ РАЗМОРОЗКА     │         │       ПОЛНАЯ УТИЛИЗАЦИЯ       │
│  Восстановление на серверах.  │         │  Удаление из БД и конфигов,   │
│  Юзеру НЕ НУЖНО перенастраивать│         │  IP-адреса и слоты возвращены │
│  свои устройства!             │         │  в свободный пул              │
└───────────────────────────────┘         └───────────────────────────────┘
```

### 5.1. Защита от перепродажи и раздачи
* Куплено 3 устройства = ровно 3 активных токена/ключа во всей инфраструктуре.
* Если пользователь скинул ссылку от Слота 1 другу:
  - У каждого слота в VLESS стоит `limitIp: 1` (или 2 на случай смешанного Wi-Fi/LTE).
  - При попытке одновременного серфинга сервер сбрасывает второе подключение.
  - Чтобы подключить друга легально, пользователь обязан выделить ему отдельный Слот 2 или Слот 3 из своего пакета.
* Захотел отключить друга? Нажал «Сбросить Слот» в ЛК — старый токен аннулирован, друг отключен, слот свободен.

## 6. План внедрения

1. **База данных (`vpn_shop.db`):**
   - Таблица `subscription_slots` (связь `sub_id`, `slot_id`, `name`, `type`, `target_server`, `credentials_json`).
   - Синхронизация в `failback_merge.py`.
2. **Бэкенд (`subjson-service/app.py` & `awg_manager.py`):**
   - Эндпоинты замера пинга (`/ping`).
   - Эндпоинты генерации и управления слотами (`/api/slots/...`).
3. **Фронтенд ЛК:**
   - Компонент управления слотами устройств.
   - JS-модуль замера задержки до серверов.
   - Модальное окно генерации QR-кода.
